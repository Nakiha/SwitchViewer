# v23 显示节奏模式

2026-10-02。均匀优先显著减少挤帧，但本轮没有证明它能同时保持最低时延。因此保留低时延默认，新增可选均匀优先；没有降低分辨率，也没有承诺稳定 2× 或消除所有卡顿。

## 行为与职责

入口为悬浮面板的来源 → 游戏 → 显示节奏。游戏未运行且垂直同步关闭时可选择；下一次启动生效，启动环境为 `SWITCHVIEWER_GAME_CADENCE`。空值或未知值使用 `lowLatency`。运行期间设置禁用，日志标记真实选择值。

`GameFramePresentationPolicy` 计算请求持续时间，`GameHook` 调用 Metal 呈现方法，提交队列与 Drawable 租约不增加 CPU 等待或源帧缓冲。只对相邻已提交序号生效，缺失前帧不额外等待；持续时间为 3 ms、源周期的 15%、剩余时隙扣除安全预留三者的最小值。同步路径保持原策略。

采用 [Apple 的 present(_:afterMinimumDuration:)](https://developer.apple.com/documentation/metal/mtlcommandbuffer/present(_:afterminimumduration:))。它指定前一 Drawable 的最短显示持续时间，并非这帧最多增加多少等待；实际合成、呈现阶段可能增加更多时间。原有绝对截止检查仍在提交前执行，不能据此保证硬件呈现不会晚于名义时隙。

## 真实 Metal 回放结果

`Artifacts/v23-mode-final/summary.json` 保留两组交替对照与一组 1 秒 Drawable 阻塞恢复；五轮全部通过。性能中位数只含两组正常对照，故障注入不参与。输入取自鸣潮源间隔，约 44.7 fps；3024×1898 输出、清晰档、关闭同步。运行捕获、Apple 插帧和实际 Metal 呈现，未复现游戏内容与 GPU 绘制负载。

| 指标 | 低时延 v22 基线 | 均匀优先 v23 |
| --- | ---: | ---: |
| 实际呈现帧率 | 82.73 fps | 81.98 fps |
| 原帧取帧到呈现 P50 | 35.50 ms | 43.93 ms |
| 原帧取帧到呈现 P95 | 48.54 ms | 50.68 ms |
| 小于 3 ms 的相邻呈现间隔 | 8.14% | 0.00% |
| 大于 25 ms 的相邻呈现间隔 | 6.09% | 0.52% |

这是呈现回调时间戳的比较，不是输入到光子时延。短间隔消失也不等于所有间隔都均匀；仍有长间隔及不足 2× 的交付。每组均匀优先有至少 869 帧覆盖新路径。故障轮中 Drawable 获取等待 1001 ms，期间仍产生 44 个源帧，恢复后一秒呈现 80 帧；零帧序错误、零过期提交、像素与资源边界检查通过。

间隔阈值使用 0.001 ms 容差，避免将 25.000083 ms 之类的时间戳微小偏差算作长间隔。原始时间戳未修改；两种模式按相同口径重新统计。初始无容差口径对应 6.55% → 1.77%，不能将统计口径修正当作新增的性能改善。

## 排除的替代方案

统一源帧时钟与提前定时呈现提高部分回放的帧率，但原帧 P50 多等待约 12 ms；CPU 节拍约束在不同轮次中增加约 4–7 ms，并未稳定消除短间隔。两类实验代码已移除。只保留独立的最短显示持续时间策略，便于解释、选择和回归比较。

## 实际鸣潮接入

通过 App 以均匀优先启动鸣潮，日志 `4237966A-268F-475B-B015-336365868B1D.log` 确认 `pipeline=cadence-v23 cadence=uniform`。进入原有游戏场景，以面板按钮录制 30 秒、保持游戏前台可见；没有改变游戏图像设置或操作任务、战斗。

`wuwa-v23-uniform-integration-summary.json`：1060 个游戏提交、2000 次呈现，源帧约 35.34 fps、输出 66.71 fps（约 1.89×）；原帧 P50 41.45 ms、P95 45.28 ms。小于 3 ms 间隔为零，超过 25 ms 为 2.50%，最长 45.07 ms；1880 帧覆盖新调用。零记录丢失、零帧序错误，所有可见性采样均为前台可见。1060 个直接 GPU 捕获配对、1998 个完整呈现阶段及提交仲裁检查通过。没有出现分析器定义的大停顿。

这轮源帧不足 45 fps、没有实际游戏的低时延对照，也不是正常战斗压力。因此只确认接入与数值路径有效，不声称它相对低时延改善了游戏性能。原帧 GPU 完成到呈现 P50 22.67 ms、插帧处理 P50 11.27 ms，仍有显示等待与长间隔。

录制完成后通过 App 退出本次测试启动的游戏，恢复低时延选择和原有关闭同步配置。检查新增设置布局无重叠、运行期间禁用、开启同步后禁用及关闭后恢复。自动检查包括 59 项 Swift 测试、11 项 Python 测试（包含阈值误差回归），以及 release 构建和应用签名验证。不能把回放结果当作正常战斗改善保证。
