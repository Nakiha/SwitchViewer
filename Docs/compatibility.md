## 已知限制

云端 Xcode 27 虚拟机的 Apple 插帧能力查询为支持，实际处理返回 `-19740`。CI 明确跳过两项 Apple 实机测试，不将其计为通过；本机 M5 上这两项默认运行并通过。

- 插帧使用邻帧与额外缓冲，会增加等待时间；高分辨率中间帧可能由最高 1080p 代理生成后放大。
- iPad 声音目前直接播放，没有按插帧画面缓冲补偿，开启插帧可能音画不同步。
- 当前游戏插件默认仅接收至少 1024×576 的 SDR BGRA8 / BGRA8 sRGB 主画面；不能据此声明支持任意 Metal 游戏。
- macOS 包使用 ad-hoc 签名，尚未 Developer ID 签名和 Apple 公证。iPad 真机安装需要用户自己的签名账号，不分发通用可安装 IPA。
- App 内耗时、GPU 完成和 drawable 呈现时间均不代表完整的手柄输入到面板显示延迟。
