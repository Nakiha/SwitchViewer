# SwitchViewer 0.3.0 Preview

面向 Apple Silicon Mac 的开源游戏采集预览工具，支持可选 Apple 插帧、屏幕捕获，以及实验性鸣潮游戏内 Metal 插帧。源码还包含需自行签名安装的 iPad 版本。

## 本次更新

- macOS 采集与游戏模式支持独立设置 2× / 4× / 8× 插帧，以及插帧额外等待预算。默认 2× 保留原有时序，预算不足时丢弃超时中间帧。
- 鸣潮模式可在运行中切换倍率、等待预算、处理档位、垂直同步和显示节奏；以游戏确认的配置为准，切换失败保留旧配置。录制期间锁定设置。
- 对比素材集中保存到 SwitchViewer 素材目录；沙盒权限不足时保留源文件，支持系统目录授权、重试和重开 App 后恢复转移。
- 游戏退出使用应用的正常退出请求；游戏拒绝或尚未完成退出时提示用户，不强制终止。异常退出会显示实际状态。

## 下载与安装

下载 `SwitchViewer-0.3.0-macos-arm64.zip`，解压后将 `SwitchViewer.app` 放入应用程序目录。附带 SHA-256 文件用于校验下载内容。

安装包为 ad-hoc 签名，尚未 Apple 公证。确认下载来源可信后，按系统提示使用右键“打开”或系统设置中的“仍要打开”，无需关闭系统保护。

仅适用于 Apple Silicon Mac。基础功能声明最低 macOS 13，旧系统尚未实测；Apple 插帧需要 macOS 26 或更新版本。主要本机验证环境为 M5 / macOS 27。iPad 安装说明见仓库 `iPad/README.md`。

## 使用边界

- 本次为预览版，当前仅内置鸣潮游戏插件。其他游戏、HDR、多视口、长时间运行、各采集卡型号和不同芯片仍需验证。
- 插帧倍率代表期望输出，设备性能和等待预算可能导致中间帧被丢弃；高倍率不保证满帧率，可能增加等待并产生画面瑕疵。
- “插帧延迟”设置限制插帧额外等待预算，不是端到端输入延迟或实测 p95 延迟保证。
- 对比录制保存帧缓冲内容，不能据此测量真实屏幕呈现节奏或操作延迟。
- iPad 音频尚未按插帧视频缓冲补偿同步。

更多条件见 `Docs/compatibility.md`。问题反馈：https://github.com/Nakiha/SwitchViewer/issues 。请附系统、芯片、应用版本、游戏或采集卡型号、设置与复现步骤。
