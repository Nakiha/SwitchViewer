# SwitchViewer 0.2.0 Preview

面向 Apple Silicon Mac 的游戏采集预览工具，包含可选 Apple 插帧、屏幕捕获，以及实验性游戏内 Metal 插帧。源码同时包含需自行签名安装的 iPad 版本。

本次新增游戏插件结构：内置鸣潮适配，其他 Mac 游戏可从通用入口选择；应用识别、安装发现和画面筛选与共享插帧核心分离。另补充版本与构建元数据、自动检查、兼容性和贡献说明。

## 下载与安装

下载 `SwitchViewer-0.2.0-macos-arm64.zip`，解压后将 `SwitchViewer.app` 放入应用程序目录。SHA-256 文件用于校验下载内容。该包为 ad-hoc 签名，尚未 Apple 公证；只在信任来源时按系统提示使用右键“打开”或系统设置中的“仍要打开”，无需关闭系统保护。

包仅适用于 arm64 Mac。基础功能声明最低 macOS 13，但旧系统尚未实测；Apple 插帧需要 macOS 26 或更新版本。当前主要本机验证为 M5 / macOS 27。iPad 安装步骤见仓库 `iPad/README.md`。

## 已知限制

- 插帧会增加缓冲等待并可能产生画面瑕疵；高分辨率中间帧可能使用最高 1080p 代理。
- iPad 音频未按插帧视频缓冲作同步补偿，可能音画不同步。
- 通用 Metal 插件不保证每个游戏兼容；HDR、多视口与其他渲染接口未验证。
- 插件重构后的实际鸣潮与当前 iPad 版本、长时间运行、温度和各采集卡型号仍需真机验收。

完整边界见仓库 `Docs/compatibility.md`。故障反馈请附系统、芯片、版本、游戏 / 采集卡型号、设置与复现步骤。
